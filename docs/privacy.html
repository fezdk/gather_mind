Gather Mind

Privacy policy

Effective 18 September 2026 · Gather Mind 0.6.4

Your data stays encrypted on your device. Gather Mind's developer does not collect, receive, sell, or share your content or usage data.

Gather Mind is a local-first organisational app maintained by Nezar. It works without an account or content backend and contains no advertising, third-party analytics, tracking SDK, cloud sync, or account system. Android Internet access is included only for optional release checks and explicitly approved signed update downloads described below.

Information stored on the device

Thoughts, tags, goals, appointments, locations, appointment-plan items, and optional mood, sleep-quality, and period start/end entries are stored in an encrypted database in the app's private storage on the user's device. A random database key is held in the operating system's secure key store. Health tracking is off by default, and cycle tracking has a separate opt-in inside it. Turning either on does not transmit data or request access to another health service.

Reminder details and an optional generic count of unfinished goals are given to the device operating system solely so it can deliver notifications requested by the user. The quiet status never contains goal titles or health entries. On Android, the home-screen widget uses a bounded local summary rather than opening the main database. That summary is encrypted separately with Android Keystore and excludes health entries. Its default form contains counts and appointment times but no goal or appointment titles. Users can explicitly allow titles, with a warning that home-screen content is visible without Gather Mind's biometric lock.

Permissions

  • Notification permission is used only for locally scheduled appointment reminders and the optional quiet daily goal status.
  • Exact-alarm access lets Android deliver chosen local notification times accurately; Android falls back to less exact timing if that access is unavailable.
  • Biometric authentication is used only on the device when the user chooses to enable Lock Gather Mind. Gather Mind does not receive or store fingerprint or face data.
  • Android Internet access is available solely for optional update checks and signed update downloads. Android treats it as an install-time normal permission, so there is no runtime prompt or per-app permission switch.

The rest of the app remains usable if notification permission is denied, and the optional biometric app lock is off by default. Health tracking requires no Android health permission or sensor permission and never uses the network.

Optional update checks

Automatic update checks are off by default. If enabled in Settings & privacy → App updates, Gather Mind asks only api.github.com for the latest public Gather Mind release, at most once every 24 hours when the app opens or returns to the foreground. The request contains no thoughts, tags, goals, appointments, locations, plan items, health entries, usage history, account identifier, or Gather Mind device identifier.

Like any HTTPS request, the check exposes ordinary connection information such as the user's IP address and request metadata to GitHub, which processes it under its own terms. Gather Mind's developer does not receive update-check data. The manual option instead opens the public releases page in the user's browser, without a request from Gather Mind.

Explicitly requested in-app installation

Find updates separately asks permission to contact gathermind.control.dk via Cloudflare for a signed manifest. Install downloads app code and assets from github.com and release-assets.githubusercontent.com. No code downloads automatically. The phone verifies signatures against its pinned public certificate and checks asset hashes.

The update server and infrastructure providers receive ordinary connection metadata, including IP addresses and public runtime versions, but no user content, installation identifier, crash text or usage history. The manifest vhost has no per-request access log; operational error logs and infrastructure logs may contain connection metadata. Browser-only checking remains available without consenting to in-app requests.

Retention and deletion

Goal history stores read-only copies of each observed day's goal titles and step states in the same encrypted database. Editing or removing a goal does not change its saved previous-day records. These copies are erased by Delete all local data, clearing app storage, or uninstalling; they are not sent anywhere.

Data remains on the device until the user deletes individual items, clears health history from Health, selects Settings & privacy → Delete all local data, clears the app's storage, or uninstalls the app. Turning Health off hides its tab; turning cycle tracking off hides period history and Today cycle estimates. Neither setting deletes encrypted history. The full in-app deletion control also removes the encrypted widget summary, cancels Gather Mind's scheduled reminders, and dismisses its delivered notifications. Android operating-system backup is disabled for the app.

Children, health, and sensitive content

Gather Mind is a general organisational aid. Its optional cycle estimate is calculated only from manually entered start dates. It does not predict ovulation or fertility and must not be used for contraception or medical decisions. Gather Mind does not diagnose, treat, cure, or prevent any condition and is not a medical device or a substitute for professional care. Users decide what they enter; no entered content is sent to the developer.

Security

The local database is encrypted with SQLCipher. Its random 256-bit key is stored separately in the operating system's secure key store and is not bound to the user's biometric profile. Users can optionally require strong fingerprint or secure face authentication whenever Gather Mind returns from the background. No local-only design can protect data on a compromised device or while an authorised user has the app open.

Open-source licence

Gather Mind's source code is available under the Apache License 2.0. That software licence does not give the developer, contributors, or recipients any rights to a user's personal content.

Contact

For non-sensitive privacy or support questions, open an issue in the project's GitHub issue tracker. Do not include thoughts, goals, appointments, database files, device backups, biometric material, or other personal content in a public issue. Suspected vulnerabilities can be reported privately through GitHub.

If optional sync, accounts, analytics, or any data transfer beyond the release check described here is added, this policy and the in-app notice will be updated before that feature is released.
