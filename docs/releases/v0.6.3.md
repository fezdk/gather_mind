# Gather Mind 0.6.3

This Android beta is the first native baseline for signed in-app updates.

- **Goal history:** open History from Today to browse previous recorded days in a week strip or month calendar. Goal titles, progress and steps are read-only; missing days are not invented. Recording starts with this update.
- **In-app updates:** explicitly choose Find updates in Settings, with a browser fallback. Compatible future updates use signed packages and verified asset hashes; installation preserves saved content and drafts. Automatic checks remain off by default and never download code.
- **Date picker fix:** switching away with an appointment date picker open no longer prevents reopening it. The shared fix also covers the other date/time editors.

Install `Gather-Mind-0.6.3.apk` over your existing beta without uninstalling. Android package: `dk.fez.gathermind`; version code: **18**. The APK uses the existing beta signing certificate, not a Google Play production credential.

The first in-app update check is expected to find **no update**: no newer OTA has been activated. Existing 0.6.2 installations need this APK before they can use the new update engine.

All entered content remains encrypted on the device. Update checks/downloads contact only the disclosed update hosts; they never send thoughts, goals, appointments, health entries or usage history. The private update-signing key is not published or installed on the server.

Automated checks and APK verification do not replace physical-device testing. Update/recovery testing remains pending, and the manifest host's PHP version must be upgraded before production OTA rollout. See the README for repeatable build, signing and deployment instructions.
