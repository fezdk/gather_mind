# Gather Mind 0.6.4

Simpler update settings, with less text and clearer actions:

- One main button changes from Find updates to Install and Restart.
- Shorter explanations and confirmation; technical disclosures remain under Privacy details.
- Automatic checks remain optional and off by default. No automatic code downloads; update signatures and asset hashes are still verified.
- The Settings heading now follows the actual running app version.

This is the first signed OTA test release for the **0.6.3 baseline**. On that version, open Settings → App updates → Find updates → Install version 0.6.4. Keep the app open during installation; it saves your work before restarting. Check that Settings shows 0.6.4 afterward and that your content remains intact. Physical-device update/recovery QA is still pending.

For a direct install, use `Gather-Mind-0.6.4.apk` without uninstalling the existing beta. Package: `dk.fez.gathermind`; Android version code: **19**. An OTA changes the running app version, not the Android package version; a phone updated from the 0.6.3 APK therefore still reports package code 18 to Android.

Runtime remains `gathermind-android-1-data-8`. No native dependencies, permissions, trust keys or data schema changes. The private OTA key stays off the server and out of the release. The manifest host still needs a supported PHP version before production OTA rollout.
