# Gather Mind 0.6.5

A smoother transition when applying future in-app updates:

- A brief “Update ready. Restarting…” status before replacing the running app.
- A native reload screen in the app's current colours, with a soft fade. Reduced motion disables the fade and animated spinner.
- No extra confirmation button. Leaving or locking the app during the transition cancels the immediate restart; content and drafts are saved before reloading.

Install via **Settings → App updates → Find updates → Install version 0.6.5** on the 0.6.3 baseline or newer. The transition while installing this release is still controlled by your previous version; the improvement takes effect for subsequent updates. Physical-device transition and failure/recovery checks remain pending.

APK fallback: `Gather-Mind-0.6.5.apk`, package `dk.fez.gathermind`, Android code **20**. Install over the existing beta without uninstalling. OTA updates change the app's displayed version, not the underlying Android package version.

Runtime remains `gathermind-android-1-data-8`. No native dependency, permission, trust-key or storage-schema changes. The APK retains the existing beta signer. All entered content stays on the device. The manifest host's PHP upgrade remains required before production OTA rollout.
