# Security policy

Security fixes are made against the latest Gather Mind Android beta.

Please report a suspected vulnerability privately to [https://github.com/fezdk/gather_mind/issues](https://github.com/fezdk/gather_mind/issues) rather than opening a public issue. Include the affected version and a minimal reproduction, but do not send real thoughts, goals, appointments, database files, device backups, biometric material, signing keys, or other personal data.

Gather Mind is designed to work without an account or backend. The Android app does not request Internet access, stores user content in an on-device SQLCipher database, and keeps its database key separately in the operating system's secure storage. See [the privacy policy](mobile/PRIVACY.md) for the current data-handling model.
